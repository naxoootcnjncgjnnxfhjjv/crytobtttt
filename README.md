# crytobtttt

Este repositorio contiene un ejemplo básico de CryBot implementado en Node.js que utiliza la librería `node-telegram-bot-api`. El bot lee el token de Telegram desde un archivo de entorno.

## Uso

1. Instala las dependencias con `npm install`.
2. Crea un archivo `.env` con `BOT_TOKEN=tu_token_de_telegram`.
3. Ejecuta el bot con `node index.js`.
